# Emberveil: game downloads

This repository only holds **game client builds** (the launcher and the game) for Emberveil playtesters.
The game itself is closed source; no source code lives here.

**Play:** download the launcher for your system from the [latest release](https://github.com/MemziNET/emberveil-releases/releases/latest), extract it into its own folder and run it. It downloads the game and keeps it up to date every time you start it.
